# CS-465 Full Stack Development I

## Travlr Getaways | MEAN Stack Web Application

### Project Overview

This repository contains my coursework and development projects for CS-465 Full Stack Development I at Southern New Hampshire University (SNHU). The primary project, **Travlr Getaways**, focuses on developing a full-stack travel and hospitality web application using the MEAN stack: MongoDB, Express.js, Angular, and Node.js.

The application is being developed incrementally throughout the course, beginning with a customer-facing website served through Node.js and Express.js.

### Module One: Node.js and Express Web Application

In Module One, I established the initial application structure using Node.js and Express.js. I integrated the provided Travlr Getaways website template into an Express application and configured the server to deliver the website's static resources.

**Key accomplishments:**
- Initialized a Node.js project and installed Express.js.
- Configured an Express web server using `app.js`.
- Organized HTML, CSS, and image assets inside the `public` directory.
- Implemented static file serving through Express middleware.
- Configured the `npm start` command.
- Tested the customer-facing website and its navigation through `http://localhost:3000`.
- Committed and pushed the application to the `module1` GitHub branch.

### Technologies Used

- **Node.js:** JavaScript runtime environment.
- **Express.js:** Web application framework and static file server.
- **HTML5 and CSS3:** Customer-facing website structure and styling.
- **Git and GitHub:** Version control and project management.
- **Visual Studio Code:** Development environment.

MongoDB and Angular will be incorporated during later stages of the course.

### Running the Application Locally

1. Clone this repository and switch to the `module1` branch.
2. Open the repository directory in Terminal.
3. Install project dependencies:

   `npm install`

4. Start the Express server:

   `npm start`

5. Open `http://localhost:3000` in a web browser.
